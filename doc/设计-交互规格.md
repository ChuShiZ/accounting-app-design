# 设计-交互规格

> 状态：定稿 ｜ 关联：ADR-023 / 批次2/4/8
> 无原型参照的新增交互 + 原型行为补充——充值表单、删除交互体系、二级 Sheet 行为、导入报告、全局反馈

## 1. 充值交互（批次4，储值卡）

**入口**：储值卡编辑 Sheet 操作区"充值"按钮（非储值卡不显示）。

**充值 Sheet（二级）字段**：

| 字段 | 规则 |
|---|---|
| 实付金额 | 必填 >0（amount-md tnum，元） |
| 到账金额 | 默认=实付；可改（充 200 送 200 填 400）；**到账 > 实付时显示"赠送 ¥X"提示** |
| 日期 | 默认今天，可改 |
| 备注 | 可选 |

**校验**：实付 > 0；**到账 ≥ 实付**（违反拦截 Toast"到账金额不能小于实付"）。

**保存**：`recharge()` 双流水事务（expense 实付计支出 + recharge 到账驱动余额）→ 关闭 → Toast"充值成功" → 卡片余额刷新。

## 2. 删除交互体系

### 入口清单

| 删除对象 | 入口 | 确认提示 |
|---|---|---|
| 流水 | 流水编辑 Sheet"删除"按钮（编辑模式） | 「删除这笔流水？」无联动 |
| 储值卡 | 卡片编辑 Sheet"删除卡片"（危险色文字） | 「将删除 N 条消费/充值记录，M 笔充值支出保留？」（联动数量） |
| 非储值卡 | 卡片编辑 Sheet"删除卡片" | 「删除这张卡片？」（直接删，无联动） |
| 周期支出 | 周期详情/编辑 Sheet"删除周期" | term 有还款流水：「删除 N 条还款流水？」；recurring 直接删 |
| 类别 | 类别管理页删除项 | 「删除 N 条流水？保留则归【其他】」 |

### 确认对话框（统一样式，不用系统 AlertDialog 默认）

- **底部 alert Sheet**（radius-xl 顶，DESIGN.md 危险态 §2.4⑨）
- 标题：「删除 X？」；描述：联动数量与后果（**删除一律询问 + 可配置默认**，ADR-005）
- 按钮：取消（secondary 实底）+ 删除（**danger 文字/边框幽灵按钮**，不整片红底）
- 确认 → Repository 事务删除 + 全局刷新 + Toast"已删除"

## 3. 二级 Sheet 行为（原型还原）

- 二级 Sheet（有效期编辑 / 提前还款 / 周期编辑 / 充值 / 筛选抽屉）：**先关一级详情，再开二级**（不层叠）
- 二级关闭 → 回到列表页（一级已关）
- 实现：一级/二级均 `showModalBottomSheet`；开二级 = `Navigator.pop()`（关一级）→ `showModalBottomSheet`（开二级）

## 4. 导入结果报告 UI（批次8）

- 导入完成 → **报告底部 Sheet**：
  - 顶部：「导入完成」+ 汇总（成功 N 条 / 重复 M 条 / 失败 K 行，成功绿、失败红）
  - 失败行列表：行号 + 原因（滚动）
  - 全部失败空态：「无成功导入」+ 失败列表
  - 底部：完成（关闭）
- 失败行不计入库（Excel 导入文档 §校验规则）

## 5. 全局反馈汇总

| 触发 | Toast |
|---|---|
| 保存流水 | 「已记一笔 ¥X」 |
| 更新流水 | 「已更新」 |
| 删除（流水/卡/周期/类别） | 「已删除」 |
| 充值成功 | 「充值成功」 |
| 还款/提前还款 | 「已还款」「提前还款成功」 |
| 导入完成 | 「导入完成：成功 N，重复 M，失败 K」 |
| 备份/恢复 | 「备份成功」「恢复成功」 |
| 校验失败 | 具体原因（如"请输入金额""到账金额不能小于实付"） |
| WebDAV 失败 | 「连接失败：{原因}」 |
