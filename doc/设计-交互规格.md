# 设计-交互规格（v16）

> 状态：v16 定稿 ｜ 原型：`../记账-app-v16/` ｜ 主设计：`设计-账户资产模型.md`
> 覆盖：记账、账户添加/编辑、资产动作、报表、类别、设置/备份、删除、搜索、反馈。
> 原则：用户界面只出现“收入/支出”，内部转账只由资产动作触发；所有删除二次确认；校验失败不关闭 Sheet。

---

## 1. 全局导航

- 4 Tab：首页 / 报表 / 资产 / 我的；中央「记一笔」按钮打开 RecordSheet。
- Tab 切换保留各自滚动位置；Sheet 打开时点击 Tab 先关闭 Sheet 再切 Tab。
- 返回按钮回到当前 Tab；类别/设置为栈内页面。
- Sheet 统一从底部弹出，长表单近全屏，顶部圆角，底部操作栏固定。
- 遮罩点击关闭 Sheet；确认弹窗点击遮罩等于取消。

---

## 2. 记一笔 / 编辑流水

### 2.1 入口

| 入口 | 行为 |
|---|---|
| 中央「记一笔」 | 全新表单，标题「记一笔」 |
| 首页流水 | 打开编辑流水，标题「编辑流水」，预填全部字段 |
| 报表排行流水 | 同上 |
| 银行卡/储值卡最近流水 | 同上 |
| 贷款还款记录 | 同上 |
| 资产页添加 | 不打开记账；打开账户表单 |

打开新记账时必须清除上一次编辑 id；关闭/取消不会污染下一次新建。

### 2.2 字段

| 字段 | 规则 |
|---|---|
| 收支类型 | 支出/收入；编辑时允许切换 |
| 金额 | 数字，最多两位小数；0/空拦截 |
| 类别 | 当前类型类别；编辑已删除类别时保留原名 |
| 账户/卡片 | 下拉只显示账户名称，**不显示余额** |
| 日期 | 默认今天；可补记；空值拦截 |
| 图片 | 原型为占位；Flutter 用 image_picker |
| 备注 | 可选 |

### 2.3 账户联动

- 支出选储值卡：余额只扣减，不再计入支出（充值已计）。
- 支出选信用卡：计入支出；还款不再计。
- 收入选存单：利息计收入，本金不计收入。
- 储值卡有默认类别时，选择该卡自动选中默认类别；用户可改。
- 账户列表不展示余额，避免录入时被余额干扰。

### 2.4 保存/编辑/删除

- 新增：保存 → 关闭 → Toast「已记一笔 支出/收入 ¥X」→ 首页/报表/账户余额刷新。
- 编辑：预填 → 保存 → Toast「已更新」；先回退旧交易，再应用新交易；账户余额、报表同步。
- 删除：编辑 Sheet 底部「删除这笔流水」→ 确认 → 回退余额 → Toast「已删除」。
- 储值卡编辑后余额不能为负；超出提示「储值卡余额不足」。
- 贷款还款流水编辑/删除时同步回退贷款本金；原型不回退下次还款日。
- 充值流水编辑/删除时同步回退储值卡余额；充值+赠送是两笔，删除一笔只回退对应部分。
- 新记账状态复位：标题「记一笔」、金额空、无删除按钮。

## 3. 添加/编辑账户

### 3.1 入口

| 类型 | 添加入口 | 编辑入口 |
|---|---|---|
| 银行卡 | 资产页 + → 添加银行卡 | 银行卡详情 → 编辑 |
| 储值卡 | 资产页 + → 添加储值卡 | 储值卡详情 → 编辑 |
| 贷款 | 资产页 + → 添加贷款 | 贷款详情 → 编辑 |
| 存单 | 资产页 + → 添加存单 | 存单详情 → 编辑 |

AddSheet 四个入口：存单、银行卡、储值卡、贷款；不再显示“后续批次实现”。

### 3.2 银行卡

字段：名称、开户行/平台、当前余额（仅新建）。
- 名称必填、唯一、≤20 字。
- 余额 ≥0；作为期初余额，创建后随流水变化。
- 编辑只改名称/开户行/备注；当前余额只读。
- 保存 Toast「已添加银行卡」/「已更新账户」；资产列表和记账账户下拉立即出现。

### 3.3 储值卡

字段：名称、商户/平台、当前余额（仅新建）、默认消费类别、备注。
- 默认类别来自支出类别，可不设置。
- 编辑可改名称/商户/默认类别；余额只读。
- 类别重命名同步账户默认类别；类别删除清空默认类别。
- 记账选择该卡时自动选中默认类别。
- 保存 Toast「已添加储值卡」/「已更新账户」。

### 3.4 贷款

字段：名称、贷款机构、贷款类型（房贷/车贷/消费贷/其他）、原始本金、剩余本金、年利率、总期数、起贷日、下次还款日、每期还款额、还款方式、备注。
- 名称必填唯一；原始本金>0；剩余本金 0..原始本金；利率≥0；期数 1–600。
- 日期必填；每期还款额≥0。
- 新建后账户余额 = `-剩余本金`；资产页显示负数。
- 详情可编辑；保存后剩余本金、进度、待办同步。
- 保存 Toast「已添加贷款」/「已更新贷款」。

### 3.5 账户保存后的联动

- 资产页对应分组出现/更新。
- 设置页「默认记账账户」下拉出现新账户。
- 记一笔支出账户下拉出现新银行卡/储值卡（不显示余额）。
- 报表不因开户/期初余额产生收入/支出。

## 4. 资产动作

### 4.1 储值卡充值

入口：储值卡详情 → 充值。
字段：实付金额、赠送金额、日期、备注。
- 实付>0；赠送≥0；付款账户余额足够。
- 实付计支出；赠送计收入；卡余额增加实付+赠送。
- 卡内消费只扣余额，不再计支出。
- 保存 Toast「充值成功」。

### 4.2 信用卡还款

入口：信用卡详情 → 还款。
字段：还款金额、日期。
- 0<金额≤待还；付款账户余额足够。
- 还款不计支出；信用卡余额向 0 靠近。
- 全额还清后待办移除。
- Toast「已还款」。

### 4.3 贷款还款

入口：贷款详情 → 还款。
字段：还款金额、日期。
- 0<金额≤剩余本金；付款账户余额足够。
- 月供整笔计支出；剩余本金减少；下次还款日顺延 1 个月。
- 不拆本金/利息。
- Toast「已还款」。

### 4.4 存单

- 添加：银行、本金、利率、存期、起存日、资金来源（可选）、名称、存单号、备注。
- 资金来源可选；选择后从该账户扣本金；余额不足拦截。
- 本金购买不计支出。
- 详情：进行中可编辑/提前支取；已到期可到期支取/转存；已关闭显示已关闭。
- 提前支取：实际利息默认 0，可改；本金回银行，利息计收入。
- 到期支取：实际利息默认预计利息；本金回银行，利息计收入。
- 转存：实际利息、新本金=旧本金+利息、新利率/存期/起存日；旧存单关闭，新存单 active；利息计收入。
- 删除：确认后删存单记录；已记利息保留。
- 保存/支取/转存 Toast 对应提示。

## 5. 报表

- 顶部下划线 Tab：周报/月报/季报/年报；左右箭头切换上一期/下一期，当前期右箭头禁用。
- 支出/收入切换影响汇总、趋势、分类、对比、排行。
- 四项汇总：本期、月均（年/季）或日均（周/月）、比上期、收支结余。
- 比上期：上一期为 0 不显示百分比，只显示绝对增减。
- 趋势：面积 + 最高点气泡 + 横轴标签（周 7 个日期、月 1/5/10/15/20/25/30、季 3 月、年 12 月）。
- 分类：环形图 + 最多 6 个外标签（左右列纵向避让）+ 分类列表；超过 6 个显示查看更多。
- 分类点击筛选排行；排行标题变「「类别」支出排行」，可清除筛选。
- 对比：近 5 期柱状；≥1 万显示 X.XX 万。
- 排行：默认 8 条，可展开全部（最多 20）；点击流水编辑。
- 不展示月度/年度小结、订阅设置、自定义周期、子分类切换。

---

## 6. 类别管理

- 支出/收入分段；列表图标按图标固定色，无底色。
- 新增/编辑：名称、收支类型、图标选择器。
- 空名称/同类型重名拦截。
- 重命名同步已有流水类别和储值卡默认类别。
- 删除：确认后删除；已有流水保留类别名；储值卡默认类别清空。
- 图标选择器每个图标显示自己的颜色；选中态用边框，不改变图标色。
- Toast「类别已添加/类别已更新/类别已删除」。

## 7. 设置 / 备份 / 搜索

### 7.1 设置

- 默认账户：记账新建时默认选中。
- WebDAV：URL 必填 http(s)；用户名/密码/目录；测试中按钮禁用；成功/失败状态行。
- 密码默认隐藏，眼睛切换显示。
- 自动备份开关；立即备份；备份列表保留 5 份。
- 恢复：选择备份 → 确认 → 恢复成功；取消不恢复。

### 7.2 搜索

- 关键词匹配类别、备注、账户名。
- 有结果按日期分组；无结果显示「没有匹配记录」和清除提示。
- 清除恢复全部。

---

## 8. 删除与确认

| 对象 | 入口 | 确认/联动 |
|---|---|---|
| 流水 | 编辑 Sheet 删除 | 回退账户余额；贷款/充值关联同步；Toast「已删除」 |
| 类别 | 类别编辑删除 | 保留流水类别名；清空储值卡默认类别 |
| 存单 | 存单详情删除 | 删除存单记录；利息收入保留 |
| 账户 | v1 暂不做硬删 | 有流水只归档；Flutter 后续补 |
| 备份 | 不删除 | 服务器保留最近 5 份 |

- 统一居中确认弹窗：取消/删除；危险按钮 danger 色。
- 取消：数据不变；确认：执行并 Toast。
- 删除失败：保留原数据并提示；不得半更新。

## 9. 校验与边界

| 场景 | 预期 |
|---|---|
| 金额 0/空 | Toast「请输入金额」，Sheet 保留 |
| 空日期 | Toast「请选择日期」，Sheet 保留 |
| 储值卡消费超额 | Toast「储值卡余额不足」 |
| 编辑储值卡超额 | 按「当前余额+原交易额」判断 |
| 信用卡/贷款超额还款 | 拦截并提示，不产生正余额 |
| 充值超付款余额 | Toast「付款账户余额不足」 |
| 存单资金来源不足 | Toast「资金来源余额不足」 |
| 账户名重复 | Toast「账户名称已存在」 |
| 贷款剩余本金 > 原始 | Toast「剩余本金应在 0 到原始本金之间」 |
| 报表空期 | 合计 0、分类/排行空态、趋势无 NaN |
| 分类重名 | Toast「该类别已存在」 |
| WebDAV 空配置 | Toast「连接失败：请填写完整配置」 |

---

## 10. 反馈与状态复位

- 保存流水/更新账号/删除/充值/还款/支取/转存/备份/恢复均有 Toast。
- 校验失败不关闭 Sheet；不写数据。
- 关闭 Sheet 后：编辑 id 复位、筛选保持合理、列表刷新。
- 原型数据刷新即重置；Flutter 持久化后重启不丢。
- 长表单内容可滚动，底部按钮始终可见。
