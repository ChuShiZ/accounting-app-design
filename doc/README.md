## 架构分层

```
UI 层（页面/组件，消费仓库）
   ↓
仓库层 Repository（唯一数据出入口：增删改查、聚合、导入）
   ↓
数据层 drift（五表 + 约束）  ←→  同步层（WebDAV 备份/恢复）
```

- 页面不直接碰数据库，一律走 Repository —— 为 WebDAV 恢复（整库替换后刷新）留单一入口。
- 备份式同步无行级同步状态，数据库文件即真相。
