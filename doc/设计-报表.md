# 设计-报表（v16）

> 状态：已实现于 `../记账-app-v16/` ｜ 参考：vivo 自带记账「收支报表」｜ 版本：v16
> 原则：参考信息层级与卡片视觉；不展示月度/年度小结，避免多一屏信息；报表只回答“钱花哪了、比上期多多少、最大项是什么、哪几笔最大”。

---

## 1. 页面结构

```
收支报表

[ 周报 ] [ 月报 ] [ 季报 ] [ 年报 ]
‹ 2026年6月 ›                 [ 支出 ] [ 收入 ]

[ 本月支出 ]        [ 日均支出 ]
[ 比上月支出 ]      [ 收支结余 ]

支出趋势（面积 + 最高点气泡 + 横轴标签）

支出分类构成（环形 + 外标签 + 分类列表，可点选筛选）

月支出对比（近 5 期柱状）

2026年6月支出排行（前 8 条 + 全部排行）
```

---

## 2. 核心指标

| 指标 | 定义 |
|---|---|
| 支出 | 实际付出：消费 + 储值卡充值 + 房贷/车贷月供 + 其他利息/费用；储值卡消费不重复计 |
| 收入 | 实际到账：工资 + 利息 + 赠送 + 其他 |
| 收支结余 | 收入 − 支出 |
| 月均/日均 | 年/季按总月数均摊；周/月按天数日均 |
| 比上期 | 当前期总额 − 上一期总额；上一期有数据时附环比百分比 |
| 分类占比 | 分类金额 / 当前类型总额 |
| 排行 | 当前期单笔金额降序，最多 20 条，默认前 8 条，可展开全部 |

- 百分比超过 ±999% 时显示 `>999%` / `<-999%`，避免“+11650%”这类噪音。
- 上一期为 0 时不显示百分比，只显示“比上期多/少 ¥X”。
- 收入/支出切换后，标题与文案同步改为“收入/支出”。
- 分类占比四舍五入，允许总和不为 100%。

---

## 3. 周期与类型

- 周期：周 / 月 / 季 / 年；顶部标签为周报 / 月报 / 季报 / 年报；本期不做“自定义”。
- 左右箭头切换上一期/下一期；当前期右箭头禁用。
- 支出 / 收入切换影响：汇总、趋势、对比、分类构成、排行。
- 切换周期或类型时清空分类筛选。
- 周期标签：
  - 周：`本周 06-22 至 06-28`
  - 月：`2026年6月`
  - 季：`2026 Q2`
  - 年：`2026年`

---

## 4. 本期小结（已移除）

- 不展示 AI/月度/年度小结卡片，首页直接进入四项汇总，减少一屏信息密度。
- 参考图的 AI 卡片不照搬；不引入订阅设置、联网分析或用户画像。

---

## 5. 支出趋势

- 折线 + 渐变面积填充；支出用主色，收入用绿色。
- 最高点：虚线 + 圆点 + 气泡「X月支出 ¥X」。
- 横轴标签：
  - 周：7 个日期
  - 月：1/5/10/15/20/25/30 日
  - 季：3 个月份
  - 年：12 个月
- 数据粒度：
  - 周：7 天
  - 月：当月天数
  - 季：3 个月
  - 年：12 个月

---

## 6. 支出对比

- 近 5 期柱状图（含当前期）。
- 当前期用 `--color-primary`，历史期用 `--color-primary-soft`。
- 柱顶显示紧凑数字（≥1 万显示 `X.XX万`），柱下显示周期短标签（2月/3月/Q2/2026）。
- 高度按近 5 期最大值归一；0 只保留基线。

---

## 7. 支出分类构成

- 环形图：中心显示当前类型合计；最多 6 个主分类。
- 环形图外标签显示最多 6 个分类；按角度分左右两列，纵向避让，避免小额分类标签重叠；超长名称截断，完整名称在下方列表。
- 分类列表：
  - `#序号` + 分类图标（无底色、按图标固定色） + 分类名 + `N 笔 · X%` + 金额 + 箭头
  - 超过 6 个分类显示“查看更多/收起”
  - 点击分类 → 下方“支出排行”只显示该分类，并出现“清除筛选”
- 主分类 / 子分类：v1 只做主分类；子分类待类别体系支持后再加。
- 不把“转账”作为支出分类；内部转账不计支出。

---

## 8. 支出排行

- 当前期单笔金额降序，默认前 8 条；底部“全部排行/收起”展开最多 20 条。
- 每行：分类图标 + 备注/分类 + 日期 + 账户 + 金额。
- 收入模式：绿色正数；支出模式：红色负数。
- 分类筛选时标题变为「餐饮」支出排行。
- 点击分类可筛选；点击排行中的流水打开编辑 Sheet，可查看、修改或删除。

---

## 9. 与 vivo 参考的取舍

### 采纳

- 周/月/年（我们加“季”）周期切换 + 左右翻页。
- 支出/收入切换。
- 四项汇总：本期、月均/日均、比上期、收支结余。
- 趋势图最高点气泡。
- 近 5 期对比柱状。
- 环形图 + 外标签 + 分类列表 + 单笔排行。
- 卡片分区 + 大量留白，保持可扫读。

### 不采纳

- AI 分析/本期小结/订阅设置：自用离线 App 不做这些入口。
- 5 Tab（明细/报表/记账/发现/设置）：我们保持 4 Tab + 中央「记一笔」。
- 主分类/子分类切换：v1 类别体系还没细到子分类。
- 自动导入商户标签（微信/支付宝自动记账）：我们无外部数据源。
- “转账”作为支出分类：与我们的口径冲突（内部转账不计支出）。
- 12+ 条密集排行：首屏只放前 8 条，可展开全部。

## 10. 数据实现

`reportFor(seg, kind, offset)` 返回：

```ts
{
  from, to, income, expense, balance,
  total,            // 当前类型总额
  prevTotal, change, changePct,
  daily,
  cats: [{ name, amount, count, pct }],
  trend: number[],
  top: [{ id, category, amount, note, accountName, date, time }],
  comparison: [{ label, amount, current }]
}
```

- 周期范围：
  - 周：周一至周日
  - 月：自然月
  - 季：自然季度
  - 年：自然年
- 上期：offset − 1；对比取 offset − 4 … offset。
- 所有金额整数分（原型用元 mock，Flutter 用分）。
- 报表只读 `transaction`，不碰账户余额。
