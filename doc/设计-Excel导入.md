# 设计-Excel导入

> **v16 提示**：导入仅支持收入/支出；新增“账户”列映射，缺失时使用默认账户；转账/存单/贷款不支持导入。

> 状态：定稿 ｜ 版本：v15 ｜ 关联：D1

## 范围

- 仅支持 `.xlsx`（excel 包限制，老 .xls 不支持；文件选择器过滤）
- 仅导入**普通流水**（type=income/expense）；不支持导入卡片/周期支出
- 用途：测试数据灌入 + 批量历史数据迁移

## 模板列（固定表头，顺序不敏感）

| 列 | 必填 | 说明 |
|---|---|---|
| 日期 | 是 | 格式 `yyyy-MM-dd` 或 `yyyy/M/d` |
| 类别 | 是 | 名称匹配，不存在则自动创建（见下） |
| 类型 | 是 | `收入` / `支出`（或 `income`/`expense`） |
| 金额 | 是 | **元**（小数最多 2 位，如 12.34）；内部转分为 `round(元×100)` |
| 备注 | 否 | 文本 |

## 处理流程

```
选文件(.xlsx) → 解析 → 逐行校验 → 事务批量入库 → 结果报告
```

### 校验规则（失败行跳过并计数，不中断）
- 日期缺失/格式非法 → 跳过
- 类型非 收入/支出 → 跳过
- 金额缺失 / ≤0 / >2位小数 / 非数字 → 跳过
- 类别为空 → 归为【其他】(id=1)

### 类别匹配
- 源文件优先读取「记账分类」，为空时回退「分类筛选」；避免把更粗的筛选分类当成真实分类。
- 先经过 `ExcelCategoryMapper` 映射到现有两级分类（如 早午晚餐→餐饮、加油充电→加油、停车费→停车、水果零食→水果/零食、火车飞机→火车高铁/飞机）。
- 名称+类型匹配已有类别 → 复用；预设目标被用户删除时回退【其他】。
- 完全未识别的来源类别 → 自动创建为一级分类（`is_preset=0`），避免丢数据；同名收入/支出可分别创建。

### 去重（防重复导入）
- 判重键：`(日期, 金额, 类别id, 类型, 备注)`，与库内已存在行重复 → 跳过并计入"重复N条"
- 同一文件内重复行同样按此规则去重

## 结果报告

导入完成后展示：`成功 N 条 / 重复 M 条 / 失败 K 行（附行号列表）`

## 事务保证

- 整批导入在**单个事务**内执行：任一行失败仅该行跳过，不整体回滚
- 导入中途取消 → 已提交部分保留，报告中说明"部分导入"
