# 设计-Excel导入

> 状态：定稿 ｜ 关联：D1

## 范围

- 仅支持 `.xlsx`（excel 包限制，老 .xls 不支持；文件选择器过滤）
- 仅导入**普通流水**（type=income/expense）；不支持导入卡片/周期支出
- 用途：测试数据灌入 + 批量历史数据迁移

## 模板列（固定表头，顺序不敏感）

| 列 | 必填 | 说明 |
|---|---|---|
| 日期 | 是 | 格式 `yyyy-MM-dd` 或 `yyyy/M/d` |
| 类别 | 是 | 名称匹配，不存在则自动创建（见下） |
| 类型 | 是 | `收入` / `支出`（或 `income`/`expense`） |
| 金额 | 是 | **元**（小数最多 2 位，如 12.34）；内部转分为 `round(元×100)` |
| 备注 | 否 | 文本 |

## 处理流程

```
选文件(.xlsx) → 解析 → 逐行校验 → 事务批量入库 → 结果报告
```

### 校验规则（失败行跳过并计数，不中断）
- 日期缺失/格式非法 → 跳过
- 类型非 收入/支出 → 跳过
- 金额缺失 / ≤0 / >2位小数 / 非数字 → 跳过
- 类别为空 → 归为【其他】(id=1)

### 类别匹配
- 名称+类型匹配已有类别 → 复用（**排除 is_auto 自动类别**，避免普通支出挂到卡片子分类语义混乱）
- 不存在 → 自动创建为自定义类别（`is_preset=0, is_auto=0`——**用户类别**，类别管理页可见可删，平铺 parent_id=NULL；与实体自动类别 is_auto=1 语义区分），同名收入/支出可分别创建

### 去重（防重复导入）
- 判重键：`(日期, 金额, 类别id, 类型, 备注)`，与库内已存在行重复 → 跳过并计入"重复N条"
- 同一文件内重复行同样按此规则去重

## 结果报告

导入完成后展示：`成功 N 条 / 重复 M 条 / 失败 K 行（附行号列表）`

## 事务保证

- 整批导入在**单个事务**内执行：任一行失败仅该行跳过，不整体回滚
- 导入中途取消 → 已提交部分保留，报告中说明"部分导入"
