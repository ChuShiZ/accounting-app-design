## 2. 记账 Sheet 交互规则（批次2）

### 打开入口（三种，复用同一 Sheet）
| 入口 | 预填 |
|---|---|
| FAB（首页） | 全新：支出、金额¥0.00、类别=餐饮(预设首个)、账户=默认账户（虚拟卡）、日期=今天 |
| 流水项点击（首页/搜索） | 编辑模式：标题"编辑这笔"，预填全部字段，显示**删除按钮** |
| 卡片详情/周期详情 | 预填 type=card/period + 关联实体（记账 Sheet 复用） |

### 类型与账户联动（关键规则）
> 账户 = **默认账户（虚拟卡）+ 卡片列表**（无现金账户，ADR-023）；默认账户为系统内建卡（is_system=1，kind=bank）。
| 类型 | 账户选择 | 落库 type | 类别 |
|---|---|---|---|
| 支出 | 默认账户（虚拟卡） | **expense + channel=bank** | **支出类别（正常选，不锁卡）**——默认账户仅渠道（ADR-023） |
| 支出 | 银行卡（非储值卡） | **expense + channel=bank** | **支出类别（正常选，不锁卡）**——银行卡只是渠道（ADR-020） |
| 支出 | 储值卡 | **card + card_id** | **默认卡片配置的 default_category（ADR-022）→ 未配置回退自动子分类 → 预设首个；可切换不锁**——chips 含默认类别+全部 expense 类别；卡片关联靠 card_id |
| 收入 | 任意（默认账户/卡片） | **income（恒不挂卡）** | 收入类别 |

> **银行卡≠卡片消费（ADR-020）**：用银行卡买午餐记"餐饮"类别（分类正确），渠道=bank 仅记录；**储值卡消费默认卡片自动子分类、可切换不锁**（银座卡默认"银座购物卡"，买零食可改"购物"；卡片关联靠 card_id，ADR-021）；收入挂银行卡同理为 income，不产生 card 流水。**默认账户虚拟卡记账=expense + channel=bank**（无现金概念，ADR-023）。

### 表单校验
- 金额 > 0 才允许保存（0/空 → Toast"请输入金额"）
- 类别必选（默认预设首个，防空）
- 日期自由选择，默认今天

### 保存/编辑/删除
- 保存：事务落库 → 关闭 Sheet → 刷新列表 → Toast"已记一笔 ¥X"
- 编辑：预填 → 保存=update（type 不可变，聚合自动重算）→ Toast"已更新"
- 删除（编辑模式显示）：确认询问 → 删除流水（卡片消费/还款等触发联动，见删除联动设计）
- 取消/遮罩关闭：重置表单（下次打开为全新态）

## 3. Repository 接口清单（批次0 照单实现）

### 流水 transaction
| 方法 | 说明 |
|---|---|
| `insertTransaction(流水)` | 单条插入（普通收支） |
| `updateTransaction(id, 字段)` | 编辑；type 不可变 |
| `deleteTransaction(id)` | 删除 + 聚合联动（余额/期数自动重算） |
| `getTransaction(id)` | 详情 |
| `listHomeFeed()` | 首页：今天/昨天/更早分组 + 组总额（支出口径） |
| `queryTransactions(筛选)` | 搜索/筛选：关键词(备注/类别/卡片名) + 类别/类型/时间/金额区间 |

### 聚合统计
| 方法 | 说明 |
|---|---|
| `getOverview()` | 今日支出/本月支出/本月收入（口径见数据模型 §2.1） |
| `getReport(周期)` | 报表：支出/日均/环比/结余 + 趋势序列 + 分类构成 + 排行 |
| `getCardBalance(cardId)` | initial + Σ到账 − Σ消费（事务内聚合） |
| `getPeriodProgress(periodId)` | 已还期数/金额/剩余/进度（含 initial_*） |

### 卡片 card
| 方法 | 说明 |
|---|---|
| `createCard(卡片, 初始余额, 默认消费类别)` | 事务：建卡 + 自动子分类（【卡片】下）+ 初始余额校验 + default_category 配置 |
| `updateCard(id, 字段)` | kind 变更提示统计口径影响；is_stored_value 按 kind 强制；默认消费类别可改 |
| `deleteCard(id)` | 按卡型联动（储值卡：虚空随删+支出询问保留；非储值卡：直接删） |
| `recharge(cardId, 实付, 到账)` | **双流水事务**：expense(实付) + recharge(credit_amount)；支持赠送 |
| `deleteRecharge(rechargeId)` | 成对删除（expense + recharge） |

### 周期支出 period
| 方法 | 说明 |
|---|---|
| `createPeriod(周期)` | 事务：建周期（term/recurring）+ 自动类别 |
| `updatePeriod(id, 字段)` | 编辑；recurring 无期数 |
| `deletePeriod(id)` | 联动（term 有还款流水询问；recurring 直接删 + 自动类别回收） |
| `recordPayment(periodId, 金额, 日期)` | 生成 type=period 流水；剩余≤0 自动 settled；结清禁录 |
| `prepay(periodId, 金额)` | 提前还款：一笔大额 period 流水（期数计 1） |

### 类别 category
| 方法 | 说明 |
|---|---|
| `createCategory(类别)` / `updateCategory` / `deleteCategory(id)` | 删除联动（归【其他】）；is_fixed/is_auto 保护 |
| `listCategories(收支类型)` | 记账 Sheet 类别 chips（排除 is_auto） |

### 导入/同步
| 方法 | 说明 |
|---|---|
| `importExcel(文件)` | 校验/去重/自动建平铺类别/报告 |
| `backup()` / `restore(备份)` / `listBackups()` | WebDAV（保留5份/CRC/连接生命周期） |
| `checkLastBackup()` | 启动检查 24h 自动备份 |
