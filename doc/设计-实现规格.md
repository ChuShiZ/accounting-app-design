## 2. Repository 接口

### 2.1 账户 account

```dart
Future<Account> createBankAccount({
  required String name,
  String? institution,
  required int openingBalance,
  String? note,
});

Future<Account> createStoredAccount({
  required String name,
  String? institution,
  required int openingBalance,
  int? defaultCategoryId,
  String? note,
});

Future<Account> createLoanAccount({
  required String name,
  String? institution,
  required LoanKind kind,
  required int originalPrincipal,
  required int remainingPrincipal,
  required int rateBp,
  required int termMonths,
  required DateTime startAt,
  required DateTime nextDueAt,
  int? perAmount,
  required RepaymentMethod method,
  String? note,
});

Future<void> updateBankAccount(int id, {name, institution, note});
Future<void> updateStoredAccount(int id, {name, institution, defaultCategoryId, note});
Future<void> updateLoanAccount(int id, {...});
Future<void> archiveAccount(int id); // 有流水只归档
Future<void> deleteAccount(int id);  // 仅无流水
```

规则：
- 新建银行卡/储值卡余额作为 `opening_balance`，不是收入。
- 新建贷款：`opening_balance = -remainingPrincipal`。
- 编辑银行卡/储值卡不改余额；余额由流水派生。
- 编辑贷款可调整剩余本金；必须 `0 <= remaining <= original`。
- 名称在当前账户集合内唯一。
- 储值卡默认类别变更同步 `card_detail.default_category_id`。
- 有流水账户禁止硬删；归档不影响历史流水。

### 2.2 流水 transaction

```dart
Future<Transaction> addExpense({amount, categoryId, accountId, occurredAt, note, imagePath});
Future<Transaction> addIncome({amount, categoryId, accountId, occurredAt, note, imagePath});
Future<Transaction> updateTransaction(int id, fields);
Future<void> deleteTransaction(int id);
Future<List<Transaction>> listHomeFeed();
Future<List<Transaction>> queryTransactions(TransactionFilter filter);
```

规则：
- `amount` 分，必须 >0。
- 支出：`account.balance` 派生减少；收入增加。
- 储值卡消费：仍写 expense，但报表口径排除（正式版可用 `account.type=stored` 判断；原型用 `reportable=false`）。
- 信用卡消费：expense，账户余额更负；还款走 transfer，不计支出。
- `type` 编辑在 v16 原型允许；Flutter v1 建议锁定 type，只改金额/类别/账户/日期/备注，避免关联交易复杂化。
- 编辑/删除必须回退旧账户效果并应用新效果；储值卡编辑后余额不能为负。
- 贷款还款/充值等资产动作生成的流水 `locked=1`，普通列表禁止直接改删；应在资产动作入口处理。

### 2.3 类别 category

```dart
createCategory(name, type, icon);
updateCategory(id, name, icon, type);
deleteCategory(id, strategy); // keep -> 归其他；delete -> 删除流水
listCategories(type);
```

- 名称同类型唯一。
- 图标 key 必须在内置集合内。
- 重命名同步更新流水 `category_id`（按 id 而非名称）。
- 删除预设【其他】禁止。
- 原型类别用 name 关联流水；Flutter 用 `category_id`，不应再用名称做外键。

### 2.4 资产动作

```dart
rechargeStored(accountId, paid, bonus, occurredAt, note);
repayCredit(accountId, amount, occurredAt);
repayLoan(accountId, amount, occurredAt);
createDeposit(...);
settleDeposit(accountId, actualInterest, mode);
renewDeposit(accountId, actualInterest, newPrincipal, rateBp, termMonths, startAt);
```

- 充值：实付 expense（计支出）+ 赠送 income（计收入），同 group；储值卡 +实付+赠送；付款账户 −实付。
- 信用卡还款：transfer 银行→信用卡；不产生支出。
- 贷款还款：月供整笔 expense；分类按 kind=房贷/车贷/贷款；贷款余额增加；下次还款日推进 1 个月；贷款详情只显示本贷款流水。
- 存单购买：transfer 银行→存单；不计收支。
- 存单支取：transfer 存单→银行 + income 利息；本金不计收入。
- 存单转存：旧存单关闭；新存单本金=旧本金+实际利息；利息 income；金额成组。
- 所有资产动作必须校验余额/待还/剩余本金，禁止负余额或正负债。

### 2.5 报表

```dart
ReportData getReport(Period period, Kind kind, int offset);
```

返回 `from/to/income/expense/balance/total/prevTotal/change/changePct/daily/cats/trend/top/comparison`。
- 报表只读 transaction。
- 年：trend 12 点；季：3 点；月：当月天数；周：7 点。
- 分类按金额降序；占比四舍五入。
- 排行默认 8 条，最多 20 条；不缩写金额。
- 点击排行流水打开编辑 Sheet。

### 2.6 备份 / 设置

```dart
Future<void> testWebdav(config);
Future<void> backupNow();
Future<List<Backup>> listBackups();
Future<void> restore(Backup backup);
Future<void> saveDefaultAccount(int accountId);
Future<void> saveDeleteCategoryStrategy(Strategy strategy);
```

## 3. 表单校验

### 3.1 记一笔

| 字段 | 规则 |
|---|---|
| 金额 | >0，最多 2 位小数；0/空 Toast「请输入金额」 |
| 类别 | 必选，默认该类型第一个 |
| 账户 | 必选；列表只显示名称，不显示余额 |
| 日期 | 必选，默认今天；可补记 |
| 备注 | 可选 |
| 账户余额 | 储值卡消费不得超过卡余额；超出提示「储值卡余额不足」 |
| 编辑 | 回退旧账户效果；储值卡可用余额=当前余额+原交易额 |

### 3.2 银行卡

| 字段 | 规则 |
|---|---|
| 名称 | 必填、≤20 字、唯一 |
| 开户行/平台 | 可选、≤20 字 |
| 当前余额 | 新建必填，≥0；编辑只读 |

### 3.3 储值卡

| 字段 | 规则 |
|---|---|
| 名称/商户 | 同银行卡 |
| 当前余额 | 新建 ≥0；编辑只读 |
| 默认消费类别 | 可选，来自支出类别；记账选卡时自动选中 |

### 3.4 贷款

| 字段 | 规则 |
|---|---|
| 名称/机构 | 名称必填、唯一；机构可选 |
| 原始本金 | >0 |
| 剩余本金 | 0 ≤ 剩余 ≤ 原始 |
| 年利率 | ≥0，% 存储转 `rate_bp` |
| 总期数 | 1–600 整数 |
| 起贷日/下次还款日 | 必填 |
| 每期还款额 | ≥0，可选 |
| 还款方式 | 等额本息/等额本金/先息后本/其他 |

### 3.5 资产动作

- 充值：实付>0；赠送≥0；付款账户余额足够。
- 信用卡还款：0<金额≤待还；付款账户余额足够。
- 贷款还款：0<金额≤剩余本金；付款账户余额足够。
- 存单：本金>0；利率≥0；起存日必填；资金来源足够；实际利息≥0。

## 4. 余额与报表联动

- 新增/编辑/删除流水后，账户余额和报表必须同时更新。
- 编辑流水：先回退旧交易，再应用新交易；不得只改一边。
- 删除流水：回退账户余额；关联资产动作需按 group 处理。
- 原型已实现：贷款还款流水回退贷款本金；储值卡充值流水回退储值卡余额；普通交易回退付款账户；多笔贷款按 `loanId` 隔离还款记录。
- 原型限制：下次还款日不随删除流水回退；Flutter 应以资产动作事务处理。
- 报表分类/排行使用交易类别/备注；账户名仅作副标题。

## 5. 图标与颜色

- 分类图标 key：food/car/cart/building/fun/coffee/medical/education/phone/mortgage/card/salary/gift/interest/invest/other。
- 颜色由 `ICON_COLORS` 映射；同一图标所有页面同色。
- 图标 24px，无底色；金额仍使用收入绿/支出红/负债橙。
- Flutter 用 `lucide_icons` 或等价线性图标；不得 emoji/位图占位。
- 账户图标：bank 主色、cart 分类色、mortgage 橙色、deposit 主色。

- Repository 单测：账户新建/编辑、余额派生、储值卡/信用卡/贷款口径、存单状态、报表聚合、删除回退。
- Widget 测试：记一笔校验、账户表单校验、报表空态、长 Sheet 底部按钮。
- 集成测试：添加银行卡/储值卡/贷款 → 资产列表 → 记账 → 报表；编辑账户；删除流水。
- 固定 demo 日期：`2026-06-22`（原型/测试数据统一，避免时区漂移）。
- 金额测试使用分；断言使用精确等值，不用浮点近似。
