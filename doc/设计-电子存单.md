# 设计-电子存单（草案）

> **v16 重构提示**：存单已确定为 `account.type='deposit'` + `deposit_detail`；本文“独立 deposit 表”方案作废，流程/交互参考《设计-账户资产模型》§4.5/§6.7。以下保留为存单专题细节（利息、状态、支取/转存表单）。

> 状态：**已吸收（v16）** ｜ 关联：资产页 / 报表收入 / 备份 ｜ 版本：v15 专题细节
> 定位：银行电子存单/大额存单/定期存单的**资产记录 + 到期管理**，不是支付账户，不参与记账账户选择。
> 本文先定产品与数据设计；确认后再落到 `设计-数据模型.md`、`ANDROID_PLAN.md` 与原型。

---

## 1. 范围

### 1.1 本期（v1）做什么

- 记录存单：银行、名称、本金、年利率、存期、起存日、到期日、存单号、备注。
- 自动计算：到期日、预计利息、已存进度、剩余天数、状态。
- 列表与汇总：本金合计、预计利息合计、最近到期。
- 到期管理：到期支取、提前支取、转存、删除。
- 到期提醒：应用内提醒（30 天内 / 已到期），不做系统推送。
- 利息入账：支取/转存时把**实际利息**记为一笔收入（类别「利息」）。
- 备份恢复：存单随数据库一起备份，无额外配置。

### 1.2 本期不做

- 不做购买/赎回时的银行卡余额内部转账（见 §2.2）。
- 不做按月/季/年付息的收息计划（v2）。
- 不做自动转存执行（只做提醒与手动登记）。
- 不做部分提前支取、存单质押、转让。
- 不做存单图片（v2 可作为可选凭证）。
- 不支持 Excel 导入存单。

## 2. 核心决策

### 2.1 独立实体，不做成“卡片类型”

存单是资产，不是支付工具：

- 如果做成 `card.kind=deposit`，它会出现在记账 Sheet 的账户下拉里，污染支付账户。
- 存单需要利率、存期、起存/到期日、预计利息等字段，塞进 card 表会大量可空。
- 独立 `deposit` 表更干净，后续还能扩展理财、债券等资产。

**结论（v16 更新）：存单 = `account.type='deposit'` + `deposit_detail`；入口 = 资产页「存单」分组。以下“独立 deposit 表 + 卡片页分段”为 v15 历史方案，已作废。**

### 2.2 本金进出不记流水，只有利息记收入

- 购买存单：钱从银行卡变成存单资产，**不是支出**。记成 expense 会把“储蓄”算成“花销”，报表失真。
- 到期返还本金：也不是收入。
- 只有**实际收到的利息**记一笔 `income`，类别「利息」。
- 现有 App 没有“账户间转账”，本期不引入；存单作为独立资产记录即可。

### 2.3 状态由日期推导，不存 status 字段

- `closed_at IS NULL AND today < maturity_at` → 进行中
- `closed_at IS NULL AND today >= maturity_at` → 已到期 / 待处理
- `closed_at IS NOT NULL` → 已支取 / 已转存

避免后台任务缺失导致 status 永久停留在 active。列表查询时实时推导。

### 2.4 预计利息不存快照

`预计利息 = round(principal × rate_bp / 10000 × term_months / 12)`

- 金额一律整数分；利率用**基点** `rate_bp`（3.25% = 325），避免浮点。
- 存单未支取前，预计利息是派生值；编辑本金/利率/存期后自动重算。
- 实际利息在支取/转存时写入 `actual_interest`，作为历史快照。

## 3. 数据模型

### 3.1 deposit 存单表

| # | 字段 | 类型 | 可空 | 默认 | 说明 |
|---|---|---|---|---|---|
| 1 | id | INTEGER | 否 | 自增 | PK |
| 2 | bank | TEXT | 否 | — | 银行名（如“招商银行”） |
| 3 | name | TEXT | 否 | — | 存单名称，默认「{银行}{存期}存单」 |
| 4 | certificate_no | TEXT | 是 | NULL | 存单号/账号，选填 |
| 5 | principal | INTEGER | 否 | — | 本金，分，CHECK > 0 |
| 6 | rate_bp | INTEGER | 否 | — | 年利率基点，325=3.25%，CHECK 0–2000 |
| 7 | term_months | INTEGER | 否 | — | 存期（月），枚 1/3/6/12/24/36/60 |
| 8 | start_at | INTEGER | 否 | — | 起存日，本地 0 点毫秒 |
| 9 | maturity_at | INTEGER | 否 | — | 到期日，本地 0 点毫秒；创建/编辑时按 start+term 计算 |
| 10 | closed_at | INTEGER | 是 | NULL | 支取/转存日；非空=已关闭 |
| 11 | close_type | TEXT | 是 | NULL | maturity / early / renew |
| 12 | actual_interest | INTEGER | 是 | NULL | 实际利息，分；关闭时写入 |
| 13 | note | TEXT | 是 | NULL | 备注 |
| 14 | created_at | INTEGER | 否 | — | 创建时间 |
| 15 | updated_at | INTEGER | 是 | NULL | 更新时间 |

**约束**

```sql
CREATE TABLE deposit (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  bank TEXT NOT NULL,
  name TEXT NOT NULL,
  certificate_no TEXT,
  principal INTEGER NOT NULL CHECK (principal > 0),
  rate_bp INTEGER NOT NULL CHECK (rate_bp BETWEEN 0 AND 2000),
  term_months INTEGER NOT NULL CHECK (term_months IN (1,3,6,12,24,36,60)),
  start_at INTEGER NOT NULL,
  maturity_at INTEGER NOT NULL,
  closed_at INTEGER,
  close_type TEXT CHECK (close_type IS NULL OR close_type IN ('maturity','early','renew')),
  actual_interest INTEGER CHECK (actual_interest IS NULL OR actual_interest >= 0),
  note TEXT,
  created_at INTEGER NOT NULL,
  updated_at INTEGER,
  CHECK (maturity_at > start_at),
  CHECK ((closed_at IS NULL) = (close_type IS NULL)),
  CHECK (closed_at IS NULL OR closed_at >= start_at)
);
CREATE INDEX idx_deposit_maturity ON deposit(maturity_at, closed_at);
```

- 外键：无。存单不挂 card / period；利息收入是普通 income 流水，不挂存单。
- 删除存单不级联删利息流水（见 §5.5）。
- 备份/恢复：db 整库带走，无需额外表。

### 3.2 派生字段（不建表）

| 派生量 | 计算 |
|---|---|
| 预计利息 | `round(principal * rate_bp / 10000 * term_months / 12)` |
| 到期日 | `addMonths(start_at, term_months)`，月末按目标月最后一天收敛（1/31 + 1月 = 2/28 或 2/29） |
| 已存进度 | `(today - start_at) / (maturity_at - start_at)`，clamp 0–100% |
| 剩余天数 | `ceil((maturity_at - today) / 86400000)`，按日期 0 点 |
| 状态 | 进行中 / 待处理（已到期）/ 已支取 / 已转存 |
| 汇总 | 未关闭存单的本金合计、预计利息合计、最近到期日 |

### 3.3 类别种子

新增一个预设收入类别：

```sql
INSERT INTO category (name, icon, type, is_preset) VALUES
  ('利息', 'icon-interest', 'income', 1);
```

- 利息收入统一归「利息」，报表收入构成中单独可见。
- 图标建议 `percent` / `coins`；实现时补进图标映射表。

## 4. 业务规则

### 4.1 创建

- 银行、本金、利率、存期、起存日必填；名称不填则自动生成。
- 到期日、预计利息实时预览。
- 起存日允许补录历史存单，但 `maturity_at > start_at`。
- 同一银行可有多张存单，不限制重名。

### 4.2 编辑

- **仅“进行中”可编辑**本金/利率/存期/起存日；修改后重算到期日与预计利息。
- 已到期/已支取/已转存：只允许改名称、存单号、备注（不改金额与期限）。
- 已关闭存单再改本金/利率会造成历史口径不一致，禁止。

### 4.3 到期支取

- 条件：`today >= maturity_at` 且未关闭。
- 输入实际利息，默认=预计利息，可改（银行实际到账可能不同）。
- 本息合计 = 本金 + 实际利息，仅展示，不记本金流水。
- 若实际利息 > 0，记一笔收入：`type=income`、类别「利息」、金额=实际利息、备注「{name}到期利息」、日期=支取日。
- 关闭存单：`closed_at`、`close_type='maturity'`、`actual_interest`。

### 4.4 提前支取

- 条件：未到期且未关闭。
- 实际利息默认 0，由用户按银行实际到账填写（活期利率各行不同，不硬编码）。
- 记利息收入规则同上；关闭：`close_type='early'`。
- 提示“提前支取可能按活期计息，请以银行实际到账为准”。

### 4.5 转存

- 条件：已到期且未关闭（本期不做“提前支取后转存”）。
- 表单：新本金（默认 本金+利息）、新利率（默认原利率）、新存期（默认原存期）、新起存日（默认到期日/今天）。
- 实际利息默认=预计利息，可改；默认同时记一笔利息收入。
- 事务：旧存单关闭（`close_type='renew'`）→ 创建新存单。
- 若用户选择“利息也转存”，新本金可包含利息；利息仍记收入（权责发生），避免收入漏记。

### 4.6 删除

- 进行中/已到期：确认后直接删除记录，无流水联动。
- 已支取/已转存：确认后删除存单记录，**已记的利息收入保留**（真实收入不回滚）。
- 确认文案提示：“删除存单记录？已记的利息收入将保留。”
- 若用户之后删除了那笔利息流水，存单的 `actual_interest` 仍是历史快照，不自动同步（本期接受）。

### 4.7 提醒

- 距到期 ≤ 30 天：状态「即将到期」，首页显示提醒条。
- 已到期未处理：状态「待处理」，提醒条常驻，直到支取/转存/删除。
- 同一时间只展示最近一张（按到期日升序）。
- 点击提醒 → 资产 Tab 的「存单」分组 → 对应存单详情。
- 不做系统通知（避免通知权限与后台任务；后续可加本地通知）。

### 4.8 校验

- 本金 > 0；利率 0–20%；存期只能选预设档位。
- 名称/银行非空，长度 ≤ 50；存单号/备注 ≤ 200。
- 实际利息 ≥ 0；支取日不得早于起存日。
- 已关闭存单不可再次支取/转存。
- 转存新存单的起存日不得早于旧存单到期日（默认=到期日）。

## 5. UI / 交互

### 5.1 入口：v16 资产页「存单」分组

存单不再放卡片页分段，而是资产页的「存单」分组；右上 `+` 选择“添加存单”。

- 资产页同时展示账户、储值卡、存单、信用卡、贷款。
- 存单分组：汇总 + 列表；点击进详情。
- 以下 5.2–5.7 的列表/表单/支取/转存细节继续有效；入口文案按资产页调整。

### 5.2 存单列表

顶部汇总卡（白底、`--radius-lg`、1px 边框，不用储值卡渐变）：

```
存单本金合计       预计利息合计
¥200,000.00        ¥12,350.00
最近到期 2027-06-01 · 还有 380 天
```

列表项：

```
[银行图标] 招商银行3年存单        [进行中]
本金 ¥100,000.00    年利率 3.25%
2024-06-01 → 2027-06-01 · 剩余 380 天
预计利息 ¥9,750.00
[进度条 已存 45%]
```

- 状态徽章：进行中=primary-light/primary；即将到期/待处理=liability 浅底/橙；已支取/已转存=surface-2/disabled。
- 金额：本金中性色，预计利息 income 绿，利率 `%` 用 micro。
- 进度条：primary 填充（资产进度，区别于负债橙）。
- 排序：进行中按到期日升序 → 待处理按到期日升序 → 已关闭按关闭时间倒序。
- 空态：「还没有存单」+「添加第一张存单」。

### 5.3 添加/编辑存单 Sheet

底部 Sheet，字段：

| 字段 | 控件 | 默认/规则 |
|---|---|---|
| 银行 | 文本 + 常用银行 chips | 必填 |
| 存单名称 | 文本 | 选填，失焦自动生成 |
| 本金 | 金额输入（分） | 必填 >0 |
| 年利率 | 数字（%） | 必填 0–20，两位小数 |
| 存期 | chips：3个月/6个月/1年/2年/3年/5年 | 必填 |
| 起存日 | 日期选择 | 默认今天，可补录 |
| 到期日 | 只读 | 自动计算 |
| 预计利息 | 只读金额 | 自动计算，income 绿 |
| 存单号 | 文本 | 选填 |
| 备注 | 文本 | 选填 |

- 底部：取消 / 保存。
- 编辑时标题「编辑存单」；已到期后隐藏金额/期限字段，只留名称/存单号/备注。
- 金额输入必须修掉现有 P0 的逐字格式化问题（保留原始串，blur 再格式化）。

### 5.4 存单详情 Sheet

- 顶部：银行图标 + 名称 + 状态徽章。
- 关键数字：本金、预计利息（或实际利息）、到期日、剩余天数。
- 字段行：年利率、存期、起存日、到期日、存单号、备注。
- 进度条：已存百分比 + 剩余天数。
- 操作区（按状态）：
  - 进行中：编辑 / 提前支取 / 删除
  - 待处理：到期支取 / 转存 / 删除
  - 已支取/已转存：删除（只删记录）
- 二级 Sheet：先关详情再开支取/转存/编辑 Sheet（沿用现有交互规格 §3）。

### 5.5 支取 Sheet

```
到期支取 / 提前支取
本金            ¥100,000.00
实际利息        [ ¥9,750.00 ]   （默认预计利息；提前支取默认 0）
本息合计        ¥109,750.00
[✓] 同时记一笔利息收入（类别：利息）
[取消] [确认支取]
```

- 实际利息为 0 时不生成收入流水。
- 确认后关闭 Sheet + Toast「已支取」/「提前支取成功」。
- 关闭详情 Sheet，回到存单列表。

### 5.6 转存 Sheet

```
转存
实际利息        [ ¥9,750.00 ]
新本金          [ ¥109,750.00 ]  （默认本金+利息，可改为仅本金）
新利率          [ 3.25% ]
新存期          [ 3年 ]
新起存日        [ 2027-06-01 ]
预计利息        ¥10,700.00
[✓] 记一笔利息收入
[取消] [确认转存]
```

- 确认事务：旧存单关闭为 renew + 新存单创建 + 可选利息收入。
- Toast「已转存」。

### 5.7 首页提醒

在首页「最近交易」上方插入一张提醒条（仅在有存单即将到期/待处理时显示）：

```
[银行图标] 招商银行3年存单 还有 12 天到期
预计利息 ¥9,750.00                    查看
```

- 点击：切到资产 Tab → 存单分组 → 打开该存单详情。
- 已到期未处理：文案「已到期，待支取」。
- 只有一张时显示一张；多张时显示最近一张，不堆叠。

## 6. 与现有模块的关系

| 模块 | 影响 |
|---|---|
| 首页 | 增加存单到期提醒条；概览金额不变（本金不计收支） |

| 周期支出 | 不变；存单与房贷/车贷无关联 |
| 搜索 | 不变；只搜流水，不搜资产 |
| 设置 | 不变；无新增配置（活期利率不硬编码） |
| 备份/恢复 | 自动包含 deposit 表；恢复后全局刷新 |
| Excel 导入 | v1 不支持存单；只导入普通流水 |
| 删除联动 | 存单删除不级联删利息流水（默认保留） |

## 7. Repository 接口

```dart
Future<List<Deposit>> listDeposits();                 // 进行中→待处理→已关闭
Future<Deposit?> getDeposit(int id);
Future<int> createDeposit(DepositInput input);        // 计算 maturity_at
Future<void> updateDeposit(int id, DepositInput input);// 仅 active；重算到期
Future<void> settleDeposit(int id, SettleInput input); // 到期/提前支取 + 可选收入
Future<int> renewDeposit(int id, RenewInput input);    // 旧关闭为 renew + 新建
Future<void> deleteDeposit(int id);                    // 不删利息流水
Future<DepositSummary> getDepositSummary();            // 本金/预计利息/最近到期
Future<List<Deposit>> listDueDeposits(int withinDays);// 首页提醒
```

- 写入均走事务；`settleDeposit` / `renewDeposit` 内同时插 income 流水。
- 利息收入类别按 `name='利息' AND type='income'` 查找；种子缺失时自动创建（防御）。
- 金额计算全部整数分；利率基点整数；禁止 double 落库。

## 8. 测试要点

- 利息：10 万 × 3.25% × 36/12 = 9,750 元；四舍五入到分。
- 到期日：1/31 + 1 月 = 2/28/29；跨年；2/29 + 12 月。
- 状态边界：到期日当天算「待处理」，前一天算「进行中」。
- 支取：实际利息 0 不生成收入；>0 生成且类别正确。
- 转存：旧单 close_type=renew，新单本金/利率/期限正确；收入只记一次。
- 删除：已关闭存单删除后利息收入仍在。
- 汇总：只统计未关闭存单。
- 备份恢复：deposit 数据与图片一起恢复。
