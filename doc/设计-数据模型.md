# 设计-数据模型（v16）

> 状态：v16 定稿 ｜ 主设计：`设计-账户资产模型.md` ｜ 原型：`../记账-app-v16/`
> 范围：本地 SQLite（drift）数据模型、余额派生、交易口径、资产详情、导入/备份所需字段。
> 原则：**账户中心 + 收入/支出流水 + 内部转账**；不存账户余额快照；不做多币种、投资行情、预算。

---

## 1. 核心决策

| 决策 | 说明 |
|---|---|
| Account 统一账户 | 现金/银行卡/电子钱包/储值卡/信用卡/存单/贷款都是 `account` |
| 余额派生 | `opening_balance + 收入 + 转入 − 支出 − 转出`，不存 `balance` 快照 |
| 三种交易 | `income` / `expense` / `transfer`；用户记账 Sheet 只出现收入/支出 |
| 资产详情 1:1 | 存单 `deposit_detail`、贷款 `loan_detail`、卡属性 `card_detail` |
| 资产动作成组 | 充值、还款、存单支取/转存等同 `group_id`，便于成组删除/审计 |
| 锁定交易 | 资产动作生成的流水 `locked=1`，不允许在普通流水列表直接改删 |
| 类别两级 | `parent_id` 已启用：一级分类用于汇总，二级分类用于记账 |
| 金额整数分 | 所有金额存 INTEGER 分，禁止浮点落库 |
| 备份整库 | WebDAV 备份 db + 图片；恢复覆盖整库 |

---

## 2. 枚举

### 2.1 account.type

| 值 | 含义 | 余额符号 | 可作为支出账户 |
|---|---|---|---|
| `cash` | 现金 | 正 | 是 |
| `bank` | 银行卡/借记卡 | 正 | 是 |
| `ewallet` | 支付宝/微信等 | 正 | 是 |
| `stored` | 储值卡/购物卡/会员卡 | 正 | 是 |
| `credit` | 信用卡 | 负 | 是 |
| `deposit` | 电子存单/定期 | 正 | 否 |
| `loan` | 房贷/车贷/消费贷 | 负 | 否 |

### 2.2 transaction.type

| 值 | 含义 | 进入报表 |
|---|---|---|
| `income` | 收入，账户余额增加 | 收入 |
| `expense` | 支出，账户余额减少 | 支出 |
| `transfer` | 账户间转移 | 不计收支 |

### 2.3 group_kind

`loan_payment` / `recharge` / `credit_repay` / `deposit_transfer` / `deposit_settle` / `deposit_renew`

### 2.4 资产详情枚举

- `deposit_detail.close_type`：`maturity` / `early` / `renew`
- `loan_detail.kind`：`mortgage` / `car` / `consumer` / `other`
- `loan_detail.repayment_method`：`equal_principal_interest` / `equal_principal` / `interest_only` / `other`
- `recurring_rule.frequency`：`weekly` / `monthly` / `quarterly` / `yearly`

## 4. 表结构

### 4.1 account

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | INTEGER PK | 自增 |
| `type` | TEXT | 8 种账户类型；`default` 为系统默认账户 |
| `name` | TEXT | 账户名；普通账户可编辑，默认账户固定“默认账户” |
| `institution` | TEXT | 银行/平台/商户，可空 |
| `icon` | TEXT | 内置图标 key |
| `opening_balance` | INTEGER | 期初余额，分；资产正、负债负；默认账户恒为 0 |
| `sort_order` | INTEGER | 列表排序 |
| `archived` | INTEGER | 0/1；有流水账户只归档；默认账户不可归档 |
| `note` | TEXT | 备注 |
| `created_at` / `updated_at` | INTEGER | Unix 毫秒 |

约束：
```sql
CHECK (type IN ('cash','bank','ewallet','stored','credit','deposit','loan','default'))
CHECK (type NOT IN ('credit','loan') OR opening_balance <= 0)
```

- 不存 `balance`；由查询派生。
- **默认账户**：启动时自动创建，名称固定“默认账户”，用于未指定账户的流水；不参与余额统计，不可编辑/删除。
- 删除账户规则：无流水可硬删；有流水只能归档，归档前提示余额非 0。
- 原型 `记账-app-v16/src/store.js` 为演示使用余额快照；Flutter 必须按派生实现。

### 4.2 transaction

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | INTEGER PK | 自增 |
| `type` | TEXT | income/expense/transfer |
| `amount` | INTEGER | 分，恒正 |
| `occurred_at` | INTEGER | 交易时间 |
| `category_id` | INTEGER | 收入/支出必填；transfer 为空 |
| `account_id` | INTEGER | 支出=付款账户；收入=收款账户；transfer=转出 |
| `to_account_id` | INTEGER | 仅 transfer：转入账户 |
| `group_id` | TEXT | 关联交易组 |
| `group_kind` | TEXT | 资产动作类型 |
| `locked` | INTEGER | 资产动作生成=1，普通改删入口禁用 |
| `reportable` | INTEGER | 默认 1；资产动作的内部记账腿=0，不计入首页/报表 |
| `note` | TEXT | 备注 |
| `image_path` | TEXT | 图片凭证路径 |
| `created_at` / `updated_at` | INTEGER | Unix 毫秒 |

约束：
```sql
CHECK (amount > 0)
CHECK ((type='transfer') = (to_account_id IS NOT NULL))
CHECK ((type='transfer') = (category_id IS NULL))
CHECK (to_account_id IS NULL OR to_account_id != account_id)
```

索引：`occurred_at`、`account_id`、`to_account_id`、`category_id`、`group_id`。

### 4.3 category

| 字段 | 说明 |
|---|---|
| `id` / `name` / `icon` / `type` | 类别；一级 `parent_id=null`，二级挂到一级下面 |
| `parent_id` | 两级结构：为空表示一级分类，否则为所属一级分类 id |
| `is_preset` | 系统预设 |
| `is_fixed` | 仅【其他】=1，禁删改 |

- 预设增加收入「利息」「赠送」，支出「利息支出」「手续费」「车贷」「贷款」。
- 删除类别：未使用直接删；已使用按设置归【其他】或删除流水。
- 类别图标颜色由图标 key 固定（`ICON_COLORS`），同一图标全局同色。

### 4.4 card_detail

| 字段 | 说明 |
|---|---|
| `account_id` | PK/FK → account，1:1 |
| `default_category_id` | 储值卡默认消费类别，可空 |
| `expire_at` | 有效期，可空 |
| `card_tail` | 卡号后四位，可空 |
| `credit_limit` | 信用额度，credit 可空 |
| `billing_day` | 账单日，1–28，credit 可空 |
| `repayment_day` | 还款日，1–28，credit 可空 |

### 4.5 deposit_detail

| 字段 | 说明 |
|---|---|
| `account_id` | PK/FK → account，1:1 |
| `certificate_no` | 存单号，可空 |
| `principal` | 初始本金；账户期初=本金 |
| `rate_bp` | 年利率基点（325=3.25%） |
| `term_months` | 存期：1/3/6/12/24/36/60 |
| `start_at` / `maturity_at` | 起存/到期 |
| `closed_at` / `close_type` / `actual_interest` | 关闭信息 |

派生：
- 预计利息 = `round(principal × rate_bp / 10000 × term_months / 12)`。
- 未关闭 + 未到期 = 进行中；未关闭 + 已到期 = 待处理；关闭 = 已支取/已转存。

### 4.6 loan_detail

| 字段 | 说明 |
|---|---|
| `account_id` | PK/FK → account，1:1 |
| `kind` | mortgage/car/consumer/other |
| `original_principal` | 原始本金 |
| `rate_bp` | 年利率基点 |
| `term_months` | 总期数/期限 |
| `start_at` | 放款/起始日 |
| `next_due_at` | 下次还款日，用户维护 |
| `per_amount` | 每期还款额，可空 |
| `repayment_method` | 还款方式 |

- 剩余本金 = `-account.balance`（负债余额绝对值）。
- 月供整笔计支出；不拆本金/利息。
- v1 不自动生成还款计划；还款金额由用户录，余额按还款额减少。

### 4.7 recurring_rule

| 字段 | 说明 |
|---|---|
| `id` / `name` / `type` / `amount` | 规则主体 |
| `category_id` / `account_id` | 类别/账户 |
| `frequency` / `next_due_at` / `enabled` | 频率/下次到期/开关 |
| `note` | 备注 |

- 只作为待办与预填，不后台自动记账。
- 用户确认后在记账 Sheet 保存普通交易，并推进 `next_due_at`。

### 4.8 settings

KV 结构：

| 键 | 说明 |
|---|---|
| `webdav_url` / `webdav_username` / `webdav_dir` | WebDAV 配置 |
| `default_account_id` | 默认记账账户 |
| `del_category` | `keep` / `delete` |

- WebDAV 密码存 Keystore；备份时间戳存 shared_preferences。
- 不保存 `del_card` / `del_period`；账户归档、周期规则直接删。

## 5. 余额派生

```
balance(account) =
  opening_balance
  + Σ income.account_id = id
  + Σ transfer.to_account_id = id
  − Σ expense.account_id = id
  − Σ transfer.account_id = id
```

- 余额用于账户详情/资产列表辅助展示，不作为报表指标。
- 余额不一致时以流水为准；账户期初仅作起点。
- `reportable=0` 用于资产动作中只负责余额搬运的内部腿（储值卡充值到账、贷款本金回补）；报表和首页统计只读 `reportable=1`。

## 6. 交易口径（固定）

| 场景 | 计入支出 | 流水 |
|---|---|---|
| 普通消费 | ✅ | expense |
| 储值卡充值 | ✅ | 实付支出 + 赠送收入（同 group） |
| 储值卡消费 | ❌ | expense（account=stored，只改余额，报表排除） |
| 信用卡消费 | ✅ | expense（account=credit） |
| 信用卡还款 | ❌ | transfer（bank→credit） |
| 贷款月供 | ✅ 整笔 | expense（银行）/ 余额减少 |
| 存单购买 | ❌ | transfer（bank→deposit） |
| 存单利息 | 收入 | income |
| 内部转账 | ❌ | transfer |

**一笔钱只计一次。**

## 7. 账户新增/编辑字段（v16 原型已实现）

### 银行卡

- 新建：名称、开户行/平台、当前余额（期初）。
- 编辑：名称、开户行/平台；余额由流水变化，不直接编辑。
- 名称唯一；余额不能为负。

### 储值卡

- 新建：名称、商户/平台、当前余额、默认消费类别（可选）。
- 编辑：名称、商户/平台、默认消费类别；余额只读。
- 记账选择该卡时默认选中其默认类别；类别重命名/删除同步更新。

### 贷款

- 新建/编辑：名称、贷款机构、贷款类型、原始本金、剩余本金、年利率、总期数、起贷日、下次还款日、每期还款额、还款方式、备注。
- 账户余额 = `-剩余本金`；`剩余本金` 必须在 `0..原始本金`。
- 期数 1–600；利率 ≥0；日期必填。
