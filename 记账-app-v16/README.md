## 运行

```bash
npm install
npm run dev -- --port 4321 --host 127.0.0.1
```

打开 `http://127.0.0.1:4321`。

## 本版范围

- 4 Tab：首页 / 报表 / 资产 / 我的；Tab Bar 中央「记一笔」
- 首页：本月收入/支出/结余、待办入口、最近交易、搜索
- 记账：只有支出/收入；金额逐字输入已修复（P0）；长表单使用近全屏 Sheet
- 资产：银行卡/电子钱包/储值卡/存单/信用卡/贷款列表
- 存单：添加、详情、到期支取、提前支取、转存、删除
- 资产动作：储值卡充值（计支出）、信用卡还款（不计支出）、贷款还款（整笔计支出）
- 报表：周报/月报/季报/年报 + 支出/收入切换 + 趋势/对比 + 分类/单笔排行
- 设置：默认账户、WebDAV 配置、备份/恢复

## 原型限制

- 全部数据在内存，刷新即重置。
- 添加银行卡/贷款为示例入口，后续批次实现。
- WebDAV 备份/恢复为本地模拟。
- 贷款还款不拆本金/利息，直接减少剩余本金（界面口径）。
- 金额/余额为原型 mock，未用数据库。
