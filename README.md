## 快速上手

1. **预览 Demo**：双击打开 `02-Demo原型/accounting-app.html`（推荐 Chrome/Edge）
   - 底部 4 Tab：首页 / 报表 / 卡片 / 我的
   - 首页右下「+」悬浮按钮 → 半屏快速记账（支持 mock 上传图片）
   - 房贷/车贷详情 → 「提前还款」；卡片详情 → 有效期编辑（支持无有效期）
   - 报表页底部 → 「消费排行 Top 10」（周/月/季/年）
2. **打印/分享**：`03-导出文件/accounting-app.pdf`
3. **整体发送**：直接发送本 ZIP 包，解压即用

## 功能覆盖

- 周期性支出（房贷/车贷/停车费/电话费）：剩余金额 + 进度条 + 已结清状态筛选 + 提前还款
- 卡片实体：银行卡 / 购物卡 / 理发卡 / 自定义卡，储值卡样式 + 余额 + 有效期维护
- 收支统计：周 / 月 / 季 / 年报表（趋势图 + 环形图 + 消费排行 Top 10）
- 首页：今日支出 / 本月支出 / 本月收入概览 + 分组流水列表 + 搜索（类别/类型/金额区间筛选）
- 快速记账：底部 Tab + 首页 FAB 半屏录入

## v3 样式优化（12 条）

- FAB 避让（列表末项不再被覆盖）｜分组头与卡片 16px 对齐｜组总额等宽数字
- 报表周/月/季/年 4 套数据联动（柱/线/环/汇总/明细）｜记账保存后表单统一重置
- 「我的→卡片管理」Tab 高亮跟随｜Toast 下移不压标题｜筛选按钮不换行
- 分类占比条语义色 + 数据校到合计 12,840｜「今天」组总额只算支出（¥7,038）
- 筛选抽屉补「时间」分组并生效｜消费排行本周/本月数据区分

## 已知小瑕疵（P2，非阻塞）

- 环心金额字号 amount-lg vs 规范 amount-xl（170px 环内视觉权衡）
- 趋势图无 X 轴月份/Y 轴刻度标签
- 房贷示例「已还 24 期/360 期」与起始日推算期数不完全吻合（数据口径）
- 消费排行「本月」合计与本月支出总额有差距（示例数据规模）
